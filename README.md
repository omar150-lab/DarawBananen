# موقع مدرسة دراو بنين الثانوية

موقع تعريفي بمدرسة دراو بنين الثانوية في دراو بأسوان، تأسست عام ١٩٠٤. الموقع ملف واحد (`index.html`) بدون أي مكتبات أو خوادم.

**تصميم وتطوير:** عمر الحسين صلاح الدين دياب

## المميزات
- هيدر يظهر عند التمرير، وصورة افتتاحية بفقاعات وجملة متبدلة من رؤية المدرسة
- عدّاد سنوات يُحسب تلقائيًا من ١٩٠٤
- رسالة المدرسة في سداسيات ملوّنة تظهر مع التمرير، ثم الرؤية
- إدارة المدرسة ولافتتها وشعارها
- حاسبة نسبة مئوية للطلاب
- معرض صور، وروابط صفحة فيسبوك والخريطة
- نسخة عربية وإنجليزية كاملة (زر EN، أو أضف `?lang=en` للرابط)
- قايمة للموبايل، شريط تقدّم، وتصميم متجاوب
- دعم لوحة المفاتيح وقارئات الشاشة، واحترام تفضيل تقليل الحركة

## التقنيات
HTML5 · CSS3 · JavaScript (بدون مكتبات) · خطوط Google Fonts (Reem Kufi وTajawal)

## النشر على GitHub Pages
1. أنشئ Repository جديد (مثلًا `daraw-school`) واجعله **Public**.
2. ارفع الملفين `index.html` و`README.md` في الجذر (Add file ← Upload files).
3. من **Settings ← Pages**، اختر Branch: `main` والمجلد `/ (root)`، ثم Save.
4. بعد دقيقة أو دقيقتين يظهر الرابط: `https://اسم-حسابك.github.io/daraw-school/`

## تعديل المحتوى
في آخر `index.html` يوجد الكائن `SITE`. أضف فيه المعلمين والصور وسيظهر القسم تلقائيًا:

```js
const SITE={
  teachers:[{name:"الأستاذ فلان", role:"معلم اللغة العربية", photo:"images/t1.jpg"}],
  gallery:[{src:"images/a1.jpg", caption:"وصف الصورة"}]
};
```
ضع الصور في مجلد `images` بجانب `index.html`.

> قبل النشر العام: خذ موافقة إدارة المدرسة على الصور المعروضة، خصوصًا صور الطلاب.
